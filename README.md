

 Coal Mintra is a hybrid web and app-based system built to digitize and streamline attendance, work tracking, and safety for miners. It integrates multiple dashboards for machines, employees, and sectors, along with safety circulars and reporting, offering a complete solution for modern mining site management.

---

## 🚀 Features

* ✅ **Employee Dashboard:** View attendance, shift details, and sector assignments.
* ⚙️ **Machine Dashboard:** Real-time status of machinery—availability, usage, and sector-wise mapping.
* 🧭 **Sectors Dashboard:** Mining operations are categorized into logical sectors for better tracking.
* 🧑‍⚕️ **Health & Safety Circulars:** The `circulars_dashboard.html` page displays important circulars for miner health and safety awareness.
* 📋 **Safety Reports:** Submit and monitor safety-related incidents digitally (`safety_report.html`, `safety.js`).
* 📅 **Digital Attendance System:** Shift in/out system (`shiftin.html`, `shiftout.html`) to manage miner attendance without manual effort.
* 📲 **Web + Mobile Compatible:** Designed to work on both desktop browsers and mobile devices.

## 👷🏻‍♂️ Use Case

This system is primarily built for **mining companies** that want to transition from manual logs to a digital tracking system. It improves:

* **Worker accountability**
* **Machine efficiency tracking**
* **Incident documentation**
* **Real-time insights into mining operations**
